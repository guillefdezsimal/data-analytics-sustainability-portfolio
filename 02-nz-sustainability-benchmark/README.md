# New Zealand Sustainability Benchmarking

## Executive Overview

A Power BI sustainability benchmarking dashboard designed to analyse New Zealand's climate, emissions, energy and sustainability performance in comparison with international benchmarks.

## Business Problem

Organisations need to understand how their sustainability performance compares with other countries and international benchmarks.

This project focuses on New Zealand and provides an interactive analytical environment for comparing emissions, renewable energy, energy intensity and socioeconomic indicators.

## Objectives

- Analyse CO2 emissions trends.
- Compare CO2 emissions per capita.
- Analyse renewable energy performance.
- Compare countries and regions.
- Benchmark New Zealand against international indicators.
- Provide an executive-friendly analytical interface for sustainability decision-making.

## Dataset

The project combines sustainability, emissions, energy and socioeconomic indicators covering multiple countries and years.

## Data Preparation

Data was prepared using Power BI and Power Query, including data cleaning, type standardisation, filtering and preparation of analytical fields.

## Data Modelling

The Power BI model was designed to support time-based analysis, country comparisons and sustainability benchmarking.

## Dashboard

The dashboard contains three analytical pages:

1. Executive Climate Overview
2. Emissions & Energy Performance
3. New Zealand Benchmark

## Key Insights

The dashboard enables users to identify:

- Long-term emissions trends.
- Differences in CO2 emissions per capita.
- Renewable energy patterns.
- Differences between countries.
- New Zealand's relative sustainability performance.
